# Concept exploration (process record)

Three fundamentally different compositional architectures were prototyped and rendered
before any high-fidelity work began, per the requested iterative design process.

| | Concept A — landscape narrative | Concept B — central wetland cross-section | Concept C — abstract ribbon |
|---|---|---|---|
| Structure | Continuous left-to-right strip: pressures → river/wetland strip (hydrology/habitat/trophic/function rows) → consequences | One dominant wetland cross-section; pressures/consequences as slim side panels; HHTE cascade embedded in the landform itself | A flowing hydrological "signal" that distorts, sprouts habitat, links to trophic nodes, and blooms into function |
| Strength | Familiar, easy to scan | Wetland is the literal visual anchor; habitat zonation is mechanistically derived from topography + water level | Elegant, minimal, clean line work |
| Weakness | Reads as stacked rows behind a strip — closer to an illustrated flowchart | — | Reads as a signal/timeline rather than an ecological landscape |
| Verdict | Rejected — still segmented into strip + 2 blocks | **Selected** | Rejected — abandons the literal wetland the brief specified as anchor |

`concept_a.py` / `concept_b.py` / `concept_c.py` (with the shared `helpers.py`) are the
working-fidelity prototypes rendered for this comparison — kept for provenance, not meant
to be pixel-perfect. The chosen direction (B) was carried forward and substantially refined
into `../hhte_graphical_abstract.svg` (see `../design_rationale.md` for what changed and why).
